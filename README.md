# Luach

> ## ⚠️ This library was built mostly by AI
>
> **Most of Luach — the code, the calculations and the documentation — was generated by an
> AI coding assistant.** A person directed the project and made some of the decisions in
> discussion with it, but the work itself was done by AI, and no rav or expert has reviewed
> it line by line.
>
> The sources and choices behind each calculation are listed in
> [docs/halacha/choices.md](docs/halacha/choices.md), but **it may still contain mistakes**.
> Check anything that matters (a zman, a date, a halachic default) against a trusted luach
> and your rav before relying on it. Corrections are welcome as issues.

A free, open-source Hebrew calendar and zmanim library for JavaScript and TypeScript:
Hebrew dates, holidays, parsha, learning cycles and zmanim. Zero dependencies. Runs in
Node, browsers, Deno, Bun and React Native.

> **Ask your rav. This library calculates; it does not rule.**
> Every zman names the opinion it follows and its source. Defaults are conveniences, not
> rulings.

## Install

```sh
npm install luach
```

## Quick start

```ts
import { HebrewDate, formatHebrewDate, ashkenazi, gematriya } from 'luach';

const today = HebrewDate.fromGregorian(2026, 10, 21);
today.year;  // 5787
today.month; // 8 (Cheshvan; months are numbered from Nisan = 1)
today.day;   // 10

formatHebrewDate(today);                       // "י׳ חשון תשפ״ז"
formatHebrewDate(today, { locale: ashkenazi }); // "10 Cheshvan 5787"
gematriya(5787);                               // "ה׳תשפ״ז"

// After nightfall it is already the next Hebrew day:
HebrewDate.fromGregorian(2026, 10, 21, { afterSunset: true }); // 11 Cheshvan
```

### Zmanim

```ts
import { Zmanim, getPlace } from 'luach';

// A place and the opinions its user follows. Anything left out uses a documented default.
const zmanim = new Zmanim(getPlace('jerusalem')!, { shema: 'sof-zman-shema-mga-72' });
const day = zmanim.on({ year: 2026, month: 10, day: 21 }); // or zmanim.at(new Date())

const shema = day.slot('shema'); // the user's opinion
shema.localTime(); // "08:59" (a deadline, so rounded down)
shema.opinion;     // "Latest Shema, Magen Avraham: 3 seasonal hours of a day from alos to tzeis, 72 fixed minutes"
shema.source;      // "Magen Avraham OC 58:1, 233:3; Mishna Berura 58:4; …"

day.get('sof-zman-shema-gra').localTime(); // "09:35": any opinion, by id
zmanim.next(new Date());                   // the next of the day's times, across midnight
```

Every zman explains how it was calculated, step by step, with the local time of each step:

```ts
shema.explain().text;
// "Sunrise at sea level: 06:46:33. 72 minutes before that: 05:34:33. Sunset at sea level:
//  18:00:30. 72 minutes after that: 19:12:30. 3 seasonal hours into the day from 05:34:33 to
//  19:12:30 (Magen Avraham: a twelfth of alos 72 to tzeis 72; an hour is 68.2 min today):
//  08:59:02. Shown as 08:59: rounded down, because it is a deadline."
```

Every opinion has an id (`sof-zman-shema-gra`, `tzeis-8.5`, `tzeis-rabbeinu-tam` and many more);
`Zmanim.choices('tzeis')` lists the ones for a settings screen. `zmanim.at(instant)` gives the
day *at the place*, never on the device's clock. `time` is rounded on the safe side, so it can be
displayed by cutting off the seconds; `exact` holds the exact instant. When the sun never reaches
an angle, the time is `null` with a reason rather than a guessed time.

### Right-to-left text

A Hebrew date placed inside left-to-right text can appear scrambled: the Unicode bidi
algorithm reorders spaces, digits and punctuation around Hebrew letters. Pass
`{ isolate: true }` to wrap Hebrew output in invisible Unicode isolates (U+2067 … U+2069)
that keep it together. It is opt-in because the isolates are real characters in the string.

## How Luach differs

- **Clean-room and permissive.** Written from primary sources (the Rambam, NOAA, Meeus,
  named halachic works). No code from GPL or LGPL calendar libraries. Apache-2.0.
- **Time zones from IANA via `Intl`**, never a derived "standard offset".
- Not to be confused with `luach-picker`, an unrelated date-picker widget. Luach is a
  calculation library with no UI; a picker could be built on it.
