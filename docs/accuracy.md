# Accuracy report

Generated by `scripts/accuracy-report.mjs` from the oracle tests (`npm run test:oracle`). Do not edit by hand.
Oracles are independent implementations used only in tests (see ADR-0003); a difference means one of the two is
wrong or follows another convention, and each one is explained below.

### kosher-zmanim (LGPL), 19 cities, daily 2025–2028, 42 opinions

1,126,994 comparisons: mean difference 0.2 s (both implement the NOAA equations). No difference over 1 minute except those explained:

- **Sydney, Auckland, Chatham: kosher-zmanim is one day off** (its issue #37, a sign-inverted raw offset in DST zones).
  Luach is on the requested day: see the regression test in `test/zmanim.test.ts` and the astronomy-engine comparison.
  The comparison uses kosher-zmanim's answer for the previous date.
- **Chatham chatzos, about 4–20 February (67 days in 4 years):** kosher-zmanim's transit jumps a further day when solar noon crosses 00:00 UTC.
  astronomy-engine agrees with Luach on every one of these days.
- **Grazing-sun days (19):** on these days the sun's lowest (or highest) point is within 1° of the angle, so the
  time moves by minutes for a hundredth of a degree, and the two libraries may disagree on whether the angle is reached at all:

### Why small differences remain

- Both libraries use the NOAA equations, but with different iteration and elevation constants (earth radius).
- astronomy-engine uses a full planetary model and its own refraction; differences of a few seconds are expected.
- Near the poles the sun moves almost horizontally, so tiny altitude differences become large time differences.
