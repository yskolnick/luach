# Data sources

Every dataset or table that ships in Luach, where it came from, and its licence.
Nothing ships unless its licence allows redistribution with credit.

| Data | Where in Luach | Source | Licence | Credit |
|---|---|---|---|---|
| Calendar constants (molad BaHaRaD, month length 29d 12h 793p, leap positions, dechiyos) | `src/calendar/year.ts` | Rambam, Hilchos Kiddush HaChodesh 6–8 | Public domain (12th-century work) | cited in code |
| Civil-date arithmetic | `src/time/civil.ts` | Howard Hinnant, "chrono-Compatible Low-Level Date Algorithms" | Public domain (author's dedication) | cited in code |
| Month and weekday names | `src/locales/*.ts` | Common usage; written for Luach | Apache-2.0 (ours) | — |
| Time-zone rules | not shipped; read at run time from the platform's `Intl` (IANA tz database) | IANA | Public domain | — |

| Text structure for learning cycles (tractate lengths, mishnayos per chapter, Rambam chapters, Nach chapters) | `src/learning/data.ts`, `src/learning/bavli.ts` | Counts and order from Sefaria's public structure API, checked against the cycles' published calendars (dafyomi.co.il, Dirshu, OU, Chabad) | Facts (not copyrightable); no text copied | research note 2026-10-21-learning-cycles |
| Haftara references by minhag | `src/parsha/haftaros-data.ts` | Wikipedia (EN/HE), AlHaTorah survey, Chabad's published dated pages, Sefaria calendar API (cross-check), Shulchan Aruch | Facts (verse references); no text | research note 2026-10-21-haftaros |

| City table (built-in, ~200) and full table (34,000 cities of 15,000+ people): coordinates, elevation, IANA zone, Hebrew names | `src/places/cities-data.ts`, `src/places/full-data.ts` (generated by `scripts/build-places.py`) | GeoNames cities500, cities15000, alternateNamesV2 (Hebrew names: the preferred one, and in the full table every other non-historic one); dumps of 2026-10-21 | CC-BY 4.0 | NOTICE; README |
| Local candle-lighting customs (Jerusalem 40, Haifa 30 minutes) | `LOCAL_CANDLE_LIGHTING` in `src/places/places.ts` | Peninei Halakha, Shabbat 3:2 and Zemanim 13:5 n. 11 (R. Eliezer Melamed, ph.yhb.org.il) | Facts (customs); no text beyond a short quotation | cited in code |
| Israel boundary outline | `src/places/places.ts` | drawn for Luach from public map knowledge; checked against GeoNames coordinates of places on both sides of each border (table in `test/places.test.ts`) | Apache-2.0 (ours) | — |
