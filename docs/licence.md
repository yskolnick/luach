# Licence and how to credit

Luach is free to use in any project, including commercial apps, under the
[Apache License 2.0](https://github.com/yskolnick/luach/blob/main/LICENSE).

When you redistribute it — including inside an app — include the
[NOTICE](https://github.com/yskolnick/luach/blob/main/NOTICE) text, for example on an "About"
or open-source licences screen:

> Built on Luach by Yosef Skolnick — https://github.com/yskolnick/luach

The NOTICE also credits GeoNames (CC-BY 4.0) for the city data.

Luach is a clean-room implementation: written from the Rambam, NOAA, Meeus (the method) and
named halachic works, with no code from GPL or LGPL calendar libraries. Those are used only
as test oracles and are never shipped.
