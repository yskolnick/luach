# Examples

Not part of the npm package. Build first: `npm run build`.

| Example | Run |
|---|---|
| Node script | `node examples/node/today.mjs Lakewood` |
| Browser page | `npx vite examples/browser` or any static server from the repo root, then open `examples/browser/index.html` |
| React component | copy `examples/react/LuachToday.tsx` into your app (`npm install luach`) |
| React Native screen | copy `examples/react-native/ZmanimScreen.tsx` into your app |
| HTTP server | `node examples/http-server/server.mjs` |
| CLI | `node dist/cli.js today --city Lakewood` (or `npx luach …` once published) |

Every example shows the opinion next to each time. Ask your rav: Luach calculates; it does not rule.
